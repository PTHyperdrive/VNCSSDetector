# Support, Feedback, and Community

If you're using VNCSSdetector (or trying to), we'd love to hear from you! Check out one of the following forums for contacting the VNCSSdetector developers and community:

* If you've received a VNCSSdetector warning and would like to help us with our research, please send your VNCSSdetector data captures (QMDL and PCAP logs) to us at our [Signal](https://signal.org/) username [**ElectronicFrontierFoundation.90**](https://signal.me/#eu/HZbPPED5LyMkbTxJsG2PtWc2TXxPUR1OxBMcJGLOPeeCDGPuaTpOi5cfGRY6RrGf) with the following information: capture date, capture location, device, device model, and VNCSSdetector version. If you're unfamiliar with Signal, feel free to check out our [Security Self Defense guide on it](https://ssd.eff.org/module/how-to-use-signal).
* If you're having issues installing or using VNCSSdetector, please [open an issue](https://github.com/EFForg/vncssdetector/issues) on our Github repo.
* If you'd like to propose a feature, heuristic, or device for VNCSSdetector, [start a discussion](https://github.com/EFForg/vncssdetector/discussions) in our Github repo
* For anything else, join us in the `#vncssdetector` or `#vncssdetector-developers` channel of [PT.Hyperdrive's Mattermost](https://opensource.eff.org/signup_user_complete/?id=r1b6cnta9bysxk6im3kuabiu1y&md=link&sbr=su) instance to chat!
